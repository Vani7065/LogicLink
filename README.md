# LogicLink – Natural Language to Logic Converter

**LogicLink** is a Python-based GUI tool that translates natural language statements into symbolic logical expressions. It leverages natural language processing and symbolic computation to help students and researchers understand formal logic better.

---

Features

- Converts English sentences into propositional logic.
- Uses **spaCy** for NLP and parsing.
- Uses **SymPy** to generate symbolic logic.
- Simple and intuitive GUI with **Tkinter**.
- Displays both logical expressions and textual explanations.

---

Technologies Used

- Python 3.x  
- [spaCy](https://spacy.io/) – for natural language processing  
- [SymPy](https://www.sympy.org/) – for symbolic logic manipulation  
- [Tkinter](https://docs.python.org/3/library/tkinter.html) – for GUI interface
